A computer vision-based football analysis application for detecting and tracking players, referees, and the ball across match footage.

* Developed a YOLO-based object detection and tracking pipeline.
* Implemented team assignment, ball tracking, player positioning, and tactical-map visualization.
* Extended the analysis pipeline into a Streamlit web application for automated video analysis.
